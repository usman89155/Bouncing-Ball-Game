# ⚽ 3D Bouncing Ball Simulation

## 📖 Project Overview

The 3D Bouncing Ball Simulation is a small Unity project designed to demonstrate how objects behave under gravity and interact with surfaces. It provides practical experience with Unity's physics engine and the creation of simple 3D environments.

## 🚀 Key Features

* Realistic ball movement using physics
* Gravity-based falling and bouncing
* Collision handling between objects and surfaces
* Basic 3D environment setup
* Simple and easy-to-understand Unity project structure

## 💻 Tools & Technologies

* **Unity:** 3D game development environment
* **C#:** Scripting and gameplay logic
* **Unity Physics:** Gravity, Rigidbody, and Collider components

## ⚙️ Installation & Execution

1. Download or clone this repository to your computer.
2. Launch Unity Hub.
3. Select **Add Project from Disk**.
4. Browse to the project directory and select it.
5. Open the project using a compatible Unity version.
6. Load the main scene and press the **Play** button to observe the ball simulation.
